**Kestrel Ridge — Alpine Courier** — an original 3D chase-view flight game built for make.fun's "Make the best flight game" bounty. Fly the Kestrel K-7 turboprop over a mountain valley — river, village, radio mast, windsock, sun and drifting clouds — with three missions: **Ridge Run** (5 rings, then land home), **Valley Courier** (a parcel run to Laketown Strip) and **Storm Trial** (8 rings against the clock in gusts). An arcade flight model with real trade-offs: throttle and turn discipline cost speed, stalls bite, fuel burns, and gear and flaps decide whether a landing is soft, hard, or a gear-up crash. The HUD shows airspeed, altitude and vertical speed, a heading tape, an attitude ball, throttle, fuel and airframe, a mission checklist and a minimap, and every sortie ends with a scored debrief. Plays offline in a desktop browser from its own static files — no network, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/ — pick a mission and press Enter to fly. Arrow keys pitch and roll, W/S (or Shift/Ctrl) work the throttle, G lowers the gear, F sets flaps, R restarts, P pauses.
